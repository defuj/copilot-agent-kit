Agent Directory

Each agent is a specialized expert tuned to a domain. They share project context and route work through the IT Leader orchestrator.

@frontend-nuxt Nuxt 4

Nuxt.js + Vue 3 specialist. Builds reusable components, manages state with Pinia, handles SSR hydration, and auto-imports composables.

vue 3 nuxt ui tailwind typescript pinia
@frontend-react React 19

React + Next.js expert. Implements server components, optimizes bundle splits, configures App Router, and applies Vercel performance patterns.

next.js 15 server components shadcn/ui react 19
@backend Node.js

Node.js + Express API architect. Designs RESTful routes, manages Prisma schemas, configures auth flows, and handles database migrations.

express prisma postgres jwt stripe
@laravel Laravel 11

Laravel + PHP craftsman. Builds Eloquent models, writes Artisan commands, configures queues, and structures service layers.

eloquent artisan livewire horizon
@ci3 CI3

CodeIgniter 3 specialist. Maintains HMVC modules, optimizes Query Builder, handles legacy migrations, and enforces CI3 security rules.

hmvc query builder migration myth-auth
@android Android

Android + Kotlin developer. Implements Jetpack Compose screens, manages Hilt DI, handles CameraX, and publishes to Google Play Console.

kotlin jetpack compose hilt room gpc
@flutter Flutter

Flutter + Dart specialist. Builds Material/Cupertino widgets, manages state with Bloc or Riverpod, and implements responsive layouts.

dart bloc riverpod go_router firebase
@designer Figma

Design-systems architect. Translates Figma into pixel-perfect UI, writes Impeccable design tokens, and enforces accessibility standards.

figma design systems oklch a11y
@reviewer Code Review

Code quality gate. Audits PRs for security flaws, performance regressions, anti-patterns, and enforces team conventions.

security performance anti-patterns best practices

postgresql indexing clickhouse bigquery
